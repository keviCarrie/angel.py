RANDOM PASSWORD GENERATOR 
 This is a simple, secure password generator that generates passwords based on user-defined constraints.
 It demonstrates core python fundamentals suchas loops, list manipulation and the random module
 FEATURES 
 Customizable length; choose how long you want your password to be
 Character variety; the password includes uppercase letters, numbers, lowercase letters and symbols
 TECHNICAL CONCEPTS USED 
 Lists;used for creating and editing character sets e.g (numbers + letters + symbols)
 For loop; to iterate through the required length and build the password string character by character
 input validations; ensuring user defined length meet minimum/maximum requirements
 HOW TO RUN 
 Ensure python is installed 
 Download PGEN.py
 Run the script from your terminal
